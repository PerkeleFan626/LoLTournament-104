## Coding Standards & Conventions
- **Language Stack**: HTML5, Vanilla CSS3, Vanilla JavaScript (ES6+ Modules).
- **CSS Architecture**: Use CSS custom properties for all design tokens (colors, typography, spacing). Follow responsive mobile-first or fluid responsive principles.
- **State Management**: Centralized reactive state store saved to `localStorage`.
- **Accessibility**: Ensure keyboard navigation, semantic HTML tags, and ARIA attributes for modals and tab navigation.
- **Code Quality**: Keep functions modular, avoid monolithic files, and write self-documenting code.
